# avito_ml_test_candidate_generation

# Тестовое задание: кандидатогенерация для поиска услуг

## Цель задания: разработать решение, которое для каждого поискового запроса отбирает из корпуса до **50 объявлений** - кандидатов, которые дальше идут на ранжирование.

## Метрика качества - **Recall@50**. Оценивается доля подходящих объявлений, которые решение могло поймать в топ 50 кандидатов.

## Данные

В папке `dataset/` подготовлены файлы:
* `benchmark_queries.parquet` (`search_query`, `search_location_id`, ...) — поисковые запросы.
* `benchmark_items.parquet` (`item_id`, `item_title_raw`, `item_description_raw`, item_`price`, ...) — корпус объявлений.
* `train.parquet` (`query_id`, `item_id`, ...) — пары «запрос-выбранное объявление» для обучения.

### Признаки запроса

|Поле|Описание|
|----|--------|
|search_query|текст поискового запросa|
|search_location_id|идентификатор локации, в которой выполнялся поиск|
|search_is_delivery_search|флаг поиска с доставкой (0/1)|
|search_infm_params_text|фильтры поиска в текстовом виде, может быть пустым|
|search_category|категория, в которой выполнялся поиск|

### Признаки объявления
|Поле|Описание|
|----|--------|
|item_id|идентификатор объявления|
|item_title_raw|заголовок объявления|
|item_description_raw|описание объявления|
|item_infm_params_text|параметры объявления в текстовом виде: вид услуги, тип услуги и т. п.|
|item_category_id|категория объявления|
|item_microcat_id|подкатегория объявления: более детальное деление внутри категории|
|item_price|цена|
|item_rating|рейтинг по отзывам|
|item_rating_reviews_count|количество отзывов|
|item_location_id|идентификатор локации объявления|
|item_latitude, item_longitude|координаты объявления|
|item_is_phone_hidden|флаг: телефон скрыт|
|item_is_message_forbidden|флаг: сообщения запрещены|
